What this review covers

This adviser checks 20 selected WCAG 2.2 Level A and AA criteria. For desktop and mobile software it uses W3C WCAG2ICT interpretation guidance. It uses your answers and does not inspect or change the interface. “No issue reported” applies only to the question asked; it is not a claim of full accessibility or WCAG conformance.

Use Not sure whenever you cannot verify an answer. If a feature is absent, its related checks become Not applicable. Physical hardware controls are outside this review.
